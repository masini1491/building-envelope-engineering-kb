# References

本目錄保存來源 dossier、provenance、版本、適用範圍、限制與查證資訊；不是未整理文件的堆放區。

建議分類：

- `standards/`：CNS / ASTM / AAMA-FGIA / ISO 等
- `government/`：主管機關、建研所、政府實驗室、TAF 等
- `manufacturers/`：材料／系統製造商正式技術資料
- `research/`：學術與研究報告
- `project-knowledge/`：專案文件觀察或直接參與者確認的 provenance

每份 dossier 應盡量記錄：來源組織、標題／標準號、版本、URL、查證日期、authority、適用範圍、重要觀察、限制、不可推論事項與授權限制。

受版權保護標準全文不放入本公開 repository。
