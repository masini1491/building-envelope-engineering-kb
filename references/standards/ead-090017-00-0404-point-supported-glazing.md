## 適用範圍路由（Scope routing）

本 EAD 直接對應 point-supported vertical glazing，可作本 KB 點支承玻璃研究的重要正式 European assessment reference。其價值在於補強 generic shell／plate FEA 無法自行建立的產品與系統評估脈絡。

## 知識路由（Knowledge routing）

與 structural-glass domain 的 point support、drilled glass、local bearing、fitting/interface 與 validation methodology 相關。若未來建立 façade-specific point-supported-glass solver，本 EAD 應列為 assessment-method evidence 之一，而非僅依一般 FEA software output。

## 不可推論事項

- EAD 不等於台灣專案 governing design standard。
- `point-supported` 名稱相符不代表任意 spider、孔洞、套管、墊片、preload、friction、laminated-glass interlayer、post-breakage condition 均受同一假設涵蓋。
- generic FEA model 與本 EAD 的 assessment scope 不可互相替代。
- 本 dossier 不重製 EAD 全文。

> Point-supported glass 的可靠設計仍需要把幾何、接觸、材料、破壞模式、mesh convergence、acceptance criteria 與 product/system evidence 一起建立。
