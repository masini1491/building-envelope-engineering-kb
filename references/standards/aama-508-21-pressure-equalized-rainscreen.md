## 公開可確認範圍

FGIA 官方頁面說明，AAMA 508-21 建立 pressure-equalized rainscreen wall cladding panel systems 的：

- test specimen requirements；
- apparatus；
- test procedures；
- test reports；
- minimum performance criteria。

因此本 KB 可把 AAMA 508-21 作為 **pressure-equalized rainscreen system evaluation 的 current standard routing**。

## 不可推論事項

- AAMA 508-21 是 rainscreen cladding system 的 evaluation standard，不代表所有 curtain-wall glazing joint 都自動適用同一 detail 或 acceptance criterion。
- 本 dossier 不重製付費標準的 procedure、table、numerical criteria 或 copyrighted text。
- 不得從舊版教材、舊版 AAMA 508 或網路摘要推導 current test pressure / chamber ratio / opening ratio / time constant。
- 某個 detail 被稱為 `pressure equalized`，不代表已通過 AAMA 508-21。
