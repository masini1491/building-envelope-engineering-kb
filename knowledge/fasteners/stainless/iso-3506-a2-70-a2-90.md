# ISO 3506 stainless fasteners：A2-70 與專案特殊 A2-90

## Governing standard

ISO 3506-1:2020 規範 corrosion-resistant stainless steel bolts、screws、studs 的機械與物理性質及 property classes。ISO 官方顯示此版於 2025 年完成系統性審查並 confirmed，因此截至 2026-09-02 仍為 current edition。

## A2-70

`A2-70` 是建築外殼／帷幕工程常見的不鏽鋼扣件 designation：

- `A2`：austenitic stainless fastener steel grade group
- `70`：property class designation

實際設計時應依 ISO 3506-1 適用直徑、螺紋、產品型式與 property table 取得設計／驗收所需數值；本頁不重製受版權保護表格。

## A2 不應直接等同單一 SUS grade

工程溝通常把 A2 快速理解為「304 系」，但標準上 A2 是 fastener steel grade group，不應簡化成 `A2 = SUS304 only`。

材料牌號、冷加工狀態與實際產品 certificate 仍應確認。

## A2-90：非 ISO 3506-1 標準 property class

現行 ISO 3506-1:2020 的標準 property-class system 不應被任意外插；`A2-90` 若出現在專案或製造商文件，應視為**特殊高強度產品／專案 designation**，不得自動套用不存在於 ISO 3506-1 的標準表值。

A2-90 使用時至少確認：
- manufacturer / product specification
- material / steel grade
- tensile / proof property certificate
- diameter range
- matching nut / washer requirement
- thread specification
- tightening / preload requirement（若有）
- corrosion / galling consideration
- project approval

## Design guard

- 不得因 `90` 這個名稱就自行建立 proof stress、allowable stress、torque 或 preload 值。
- ISO 3506-1 官方 scope 明確指出其並不規定 torque/clamp-force、shear strength、fatigue resistance 或 weldability；這些需求應使用相應設計依據與產品資料。
- 不鏽鋼螺栓連接需另注意 galling、異種金屬接觸腐蝕、thread engagement 與 installation control。
