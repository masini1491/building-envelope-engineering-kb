# ISO 3506 不鏽鋼緊件 A2-70／A2-90 基線

## Governing standard

ISO 3506-1:2020 規範 corrosion-resistant stainless steel bolts、screws、studs 的機械與物理性質及 property classes。ISO 官方顯示此版於 2025 年完成系統性審查並 confirmed，因此截至 2026-09-02 仍為 current edition。

## A2-70

`A2-70` 是建築外殼／帷幕工程常見的不鏽鋼扣件 designation：

- `A2`：austenitic stainless fastener steel grade group
- `70`：property class designation

實際設計時應依 ISO 3506-1 適用直徑、螺紋、產品型式與 property table 取得設計／驗收所需數值；本頁不重製受版權保護表格。

## A2 不應直接等同單一 SUS grade

工程溝通常把 A2 快速理解為「304 系」，但標準上 A2 是 fastener steel grade group，不應簡化成 `A2 = SUS304 only`。

材料牌號、冷加工狀態與實際產品 certificate 仍應確認。

## A2-90：不得當成 ISO 3506-1 標準 property class

現行 ISO 3506-1:2020 的標準 property-class system 不應被任意外插。若 `A2-90` 出現在 project specification、manufacturer literature、certificate 或其他工程文件中，應先視為**非 ISO 3506-1 標準 property class 的 project / manufacturer-specific designation**，不得自行套用不存在於 ISO 3506-1 的標準表值。

遇到 A2-90 或類似特殊 designation 時，至少確認：

- manufacturer / product specification
- material / steel grade
- tensile / proof property certificate
- applicable diameter range
- matching nut / washer requirement
- thread specification
- tightening / preload requirement（若有）
- corrosion / galling consideration
- project approval / acceptance basis

若上述資料不足，connection capacity 應標記 `INCOMPLETE`，不得由 designation 名稱自行推算。

## 設計防呆

- 不得因 `90` 這個名稱就自行建立 tensile strength、proof stress、allowable stress、torque、preload、shear strength 或 fatigue strength。
- ISO 3506-1 的 scope 不應被延伸為完整 connection design method；實際 connection capacity 還需依 applicable fastener / structural design basis、connected material 與 geometry 判斷。
- 不鏽鋼螺栓連接需另注意 galling、異種金屬接觸腐蝕、thread engagement 與 installation control。
- 私人專案文件或直接參與者確認若曾協助辨識此議題，不得成為 public repository 的 provenance；公開頁只保留可由正式公開標準支持的通用 guardrail。
