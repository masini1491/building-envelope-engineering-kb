# 鋁材有機塗裝 AAMA 2603／2604／2605 基線

## 現行版本（2026-09-02）

FGIA 已於 2026 年更新建築鋁材有機塗裝三件套：

- AAMA 2603-26 — Pigmented Organic Coatings
- AAMA 2604-26 — High Performance Organic Coatings
- AAMA 2605-26 — Superior Performing Organic Coatings

三份標準皆適用於建築產品使用之 aluminum extrusions and panels，並包含 coil coating appendix。

## 工程定位

FGIA 將 2603 / 2604 / 2605 視為由低到高的「good / better / best」性能層級，主要用於規定 factory-applied organic coating 的性能、耐候與外觀維持要求。

重要：**AAMA 2604 / 2605 是性能規範，不是單一塗料化學種類的代名詞。**

因此不應直接寫成：

- `AAMA 2605 = PVDF`
- `AAMA 2604 = powder coating`

實際 coating chemistry、resin system、primer/topcoat、film build 與產品認證應回到塗料製造商資料及專案規範確認。

## 建築外殼應用

常見於：

- 帷幕牆鋁擠型
- 鋁板／金屬外牆板
- 門窗與其他 exterior architectural aluminum products

設計／送審時應至少確認：

- 專案要求的 AAMA 等級與版次
- substrate / pretreatment
- coating system 與製造商產品
- factory application / coil coating 路徑
- color / gloss / appearance requirement
- warranty 與 exposure 條件
- 是否另有專案加嚴測試或限制

## 不可推論事項

- 符合某塗料化學名稱不等於自動符合 AAMA 2604 或 2605。
- AAMA 2605 不表示所有顏色、光澤、金屬色或特殊效果具有相同性能或保固。
- 本頁不保存 film thickness、weathering duration、color-retention limit 等受正式標準控制的細部數值；正式採購／驗收應查閱當版標準與產品認證資料。
