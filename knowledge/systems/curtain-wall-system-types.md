# 帷幕牆系統型式：直橫料式（Stick）／單元式（Unitized）／半單元式（Semi-Unitized）

## 直橫料式系統（Stick system）

直橫料式／構件式帷幕通常由現場逐支安裝 mullion / transom，再安裝玻璃／面板與壓條、gasket、sealant 等。

工程特徵：
- 現場組裝比例高
- floor-to-floor mullion continuity / splice design 很重要
- transom-to-mullion joint、field seal、現場 tolerance 管理重要
- 安裝速度通常較 unitized 慢，但現場調整彈性較大

## 單元式系統（Unitized system）

單元式帷幕通常在工廠預組完整 panel unit，現場吊裝並透過 unit-to-unit interlock / stack joint 與樓板繫件完成系統。

工程特徵：
- factory assembly / QA 比重高
- male/female mullion interlock、stack joint、pressure equalization、drainage path 關鍵
- inter-story movement / thermal movement 需由 unit joint 與 anchor arrangement 吸收
- lifting / transportation / installation sequence 會影響設計

## 半單元式／混合式系統

半單元式／混合式系統沒有唯一跨市場命名。常見情況是部分 framing 或 glazed panel 在工廠預組、其餘現場完成。

因此遇到 `semi-unitized` 不應只靠名稱判斷 load path；應讀：
- shop drawing
- system section
- anchor arrangement
- factory / field assembly scope
- joint / drainage details

## 結構比較防呆

三種系統不是「同一份 mullion calculation 換名稱」。不同系統的：

- support condition
- splice / interlock stiffness
- anchor location
- tributary load
- joint movement
- water path
- fabrication / installation tolerance

可能完全不同。

## 水管理

Unitized 系統的 stack joint / interlocking chamber 常利用 pressure equalization、multiple seals 與 drainage chamber；stick 系統則常依 pressure plate / cap、gasket、sealant、weep / drainage path 配置。

不要從「unitized」或「stick」名稱直接推定一定是某種 single-line / multi-line seal；應以實際 section 為準。

## 試驗

不論系統型式，都可能需要依專案進行：
- air infiltration
- static / dynamic water penetration
- structural load
- inter-story movement
- seismic glass fallout
- field hose / field water test

試驗 specimen 必須反映實際系統接縫、anchor、splice、corner、typical / critical condition。
