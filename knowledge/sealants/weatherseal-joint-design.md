# 耐候密封（Weatherseal）接縫設計基線

## 核心標準

- **ASTM C920-18(2024)** — Standard Specification for Elastomeric Joint Sealants
- **ASTM C1193-25** — Standard Guide for Use of Joint Sealants

C920 是 sealant product classification / performance specification；C1193 則是 joint sealant 使用與設計 guide。兩者角色不同，不應互相替代。

## C920 的工程意義

C920 會依 type、grade、class、use 等分類 sealant。ASTM 明確提醒：

> 不是所有符合 C920 的 sealant 都適用所有 application 或 substrate。

因此材料送審不能只寫「符合 ASTM C920」；至少還要核對：

- Type
- Grade
- Class
- Use
- substrate compatibility
- primer requirement
- movement requirement
- exposure condition

## 接縫設計基礎

Weatherseal joint design 至少確認：

1. anticipated movement
2. joint width
3. sealant depth
4. movement capability / class
5. substrate type and surface preparation
6. adhesion / primer requirement
7. backer rod / bond breaker
8. three-sided adhesion avoidance
9. water path / drainage logic
10.施工可達性與後續維修

## 三面黏著防呆

接縫設計通常應避免 sealant 同時黏住 joint 的兩側與背面，否則會限制其正常延伸／壓縮變形。是否使用 backer rod、bond breaker tape 或其他方式應依 joint geometry 與 sealant manufacturer recommendation 決定。

## 結構矽利康與 weatherseal

Weatherseal joint 與 structural silicone glazing 不可混為同一設計流程。

- weatherseal：主要處理 air / water seal 與 movement
- structural silicone：承擔 glass / panel structural load transfer 時，應另外依 ASTM C1184、C1401、C1135 與系統供應商工程程序確認

## 相容性／黏著

即使 sealant 型號相同，不同 coating、glass coating、stone、gasket、backer rod、cleaner 或 primer 也可能改變 adhesion / compatibility。

因此重要專案應保留：
- substrate identification
- compatibility test / adhesion test requirement
- cleaning method
- primer decision
- batch / shelf-life control

## 不可推論事項

- `ASTM C920 compliant = 任意接縫都可用` 不成立。
- sealant 顏色相同不代表 chemistry / performance 相同。
- 只看 movement class 不代表 joint geometry 已正確。
- weatherseal joint 的設計值不得直接套 structural silicone bite / thickness 邏輯。
