# 複層玻璃（IGU）耐久性能與認證基線

本頁處理 insulating glass unit（IGU）的 sealing-system durability、fogging、frost／dew-point qualification 與第三方 certification routing。它不取代單片玻璃產品規格、結構耐風設計、熱性能或專案外觀要求。

## 工程邊界

應分開判斷：

`glass lite product compliance`
→ `IGU sealing-system / construction durability`
→ `completed façade structural / thermal / optical compliance`

其中任一層通過，都不能自動代表其他層也通過。

## ASTM 標準 routing

### ASTM E2188

ASTM E2188-26 是目前 ASTM 列示的 Active 版本，目的在測試預組、永久密封 IGU 的 sealing system 與 construction performance。

重要 scope boundary：

- 測試結果與試體 construction 有關；glass type、glass thickness、cavity size 等差異可能影響結果。
- 此方法不是為 continuous high-humidity exposure 或 long-term water immersion 建立的 qualification。
- 依 E2188 測試合格的 IGU，也不能因此直接推定適合 structural glazing；structural sealant 的 UV durability 與 structural properties 仍須另行確認。

### ASTM E2189

ASTM E2189-19 目前列為 Active，用於測試 IGU 對 fogging 的抵抗能力，包括由 sealing-system 或 internal components 揮發物造成的 fogging。

### ASTM E2190

ASTM E2190-19 目前列為 Active，是 IGU performance / evaluation specification。其 qualification 包含 frost／dew-point 與 specified-duration 後無 fog 等評估；若為 argon-filled specimens，另涉及指定的 gas-content qualification。

E2190 qualification 主要提供 IGU durability evaluation basis，不涵蓋所有外觀、thermophysical property、heat / light transmission 或 glass displacement 要求；也不能自動代表 structurally glazed application 已完成驗證。

## ASTM E773 歷史引用防呆

ASTM E773-01 已於 2010 年 withdrawn，ASTM 官方標示 **No replacement**。

因此遇到舊專案規範引用 E773 時：

- 忠實保存其為 project-specified requirement；
- 不得把 E773 當成 current ASTM requirement；
- 不得自行改寫成「E2190 正式取代 E773」，因為 ASTM 的 withdrawal status 並沒有建立這個 replacement 關係；
- current design / submittal review 應另外確認契約 amendment、approved clarification 與目前適用的 IGU durability standards。

## 認證計畫與 ASTM 版次

IGCC／IGMA 是 sealed insulating glass 的第三方 certification program；其公開資訊將 seal durability certification routing 到 ASTM E2190，並要求 certification 所需的測試與 program procedure。

但：

> ASTM 的 current edition 與 certification program 實際採用的 edition / protocol 是兩個不同的 freshness state。

ASTM 已發布 E2188-26；另一方面，IGCC／IGMA 目前可查的 2025 Laboratory Manual 仍明列其 adopted releases 為 E2188-19、E2189-19、E2190-19，而 2026 年公開的 specifications sheet 列出 E2188／E2189／E2190 family，但未在該 sheet 標出版次。

因此正式送審或認證前，必須同時確認：

1. ASTM current edition / status；
2. project specification 指定版次；
3. certification program 當時實際採用的 edition、manual 與 protocol。

不得因 ASTM 更新，就自動推定 IGCC／IGMA 已同步採用同一新版。

## 設計與送審防呆

- `IGCC/IGMA certified = façade structural design PASS`：錯誤。
- `ASTM E2190 qualified = thermal / optical performance PASS`：錯誤。
- `E2188 PASS = 可長期浸水使用`：錯誤。
- `E2189 PASS = 所有 IGU durability requirement 都完成`：錯誤。
- `歷史規範引用 E773 = E773 仍 current`：錯誤。
- `ASTM current edition = certification program adopted edition`：錯誤。

專案使用 IGU 時仍應依適用性另外確認 glass make-up、spacer / seal system、gas fill、coating、edge condition、structural glazing interface、thermal / optical criteria、fabrication QA 與 warranty requirements。
