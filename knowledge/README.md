# Knowledge

本目錄保存已整理、可供工程師與 AI 直接使用的技術結論。

預定主題：

- `standards/`：規範的工程摘要與 cross-reference
- `materials/`：鋁、鋼、不鏽鋼、玻璃、sealant、gasket 等
- `fasteners/`：螺絲、螺栓、property class、設計與耐蝕
- `finishes/`：烤漆、陽極處理等
- `corrosion-protection/`：熱浸鍍鋅與其他防蝕
- `structural-design/`：耐風、直料、橫料、anchor、glass、silicone 等
- `performance-testing/`：氣密、水密、結構、層間變位等
- `engineering-notes/`：標準無法單獨回答的實務問題
- `case-knowledge/`：經抽象化、可公開的專案特殊知識

每個技術結論應連回 `references/` 中可追溯的 evidence；不要在多個頁面複製同一 canonical 結論。
