# 離散鋁植釘傳力｜四站點合成彈簧網路研究

## 目的與適用邊界

這是一個 **單軸 DOF3、純量線彈性彈簧網路**，用來驗證 CalculiX `SPRING1`／`SPRING2` 內，四個離散連接位置的位移及傳力數值流程；**不是**鋁板、50 mm U 型加勁肋、實際鋁植釘、接觸／焊道或扣件的有限元素力學模型。

- 使用 repository 已有的合成 `fixtures/u_rib_stud_50x50_t3_synthetic.json` 幾何預檢，站點位於長 1200 mm 加勁肋沿長向的 150、450、750、1050 mm；**150 mm 端距只是合成 fixture 設定，使用者未指定實際施工端距**。
- 50 × 50 × 3 mm 斷面與 3 mm 面板厚度僅作幾何標籤；**未**從截面慣性矩、材料性質、植釘直徑、焊接資訊或間距推定彈簧剛度。
- 板側與肋側各有四個獨立平移節點；同側相鄰節點以線性彈簧串連；每個節點連接獨立合成接地彈簧。四個植釘站點以 `SPRING2` 逐一跨側連接，不直接拘束為等位移。
- **合成剛度設定**：板側接地 100、肋側接地 200、板側相鄰 40、肋側相鄰 400 N/mm；跨側連接依研究情境為 0、50、500 N/mm／站點。在第二個板側站點施加 +1 N 合成單軸點載重。這些數字都**不是**實際鋁植釘的校正剛度或設計荷載。
- 以獨立 8×8 剛度矩陣解析方程解與 CalculiX 最終節點 DOF3 交叉檢查，同時檢驗各節點平衡、人工接地彈簧力之合力及彈性能量恆等式。
- 各站點 `k×(U_panel−U_rib)` **僅為同一假設模型的衍生彈簧力量**，不是獨立量得的植釘力、真實扣件負載或容量。

## 執行方式

在 `tests/fea_benchmark/envelope_panels/`，需要已安裝的 `ccx`：

```bash
python -m unittest -v test_u_rib_stud_link.py
for scenario in unlinked soft stiff; do
  python check_u_rib_stud_link.py --generate "stud_link_${scenario}" "${scenario}"
  (cd "stud_link_${scenario}" && ccx -i panel)
done
python check_u_rib_stud_link.py .
```

必須使用全新目錄，且 `.inp/.dat/.sta/.frd` 都要通過精確 provenance、完成時間、正確欄位涵蓋及獨立解析解檢查後，才能聲稱這個**受限合成彈簧網路**通過。此工具不接受未驗證的任意 K、接觸條件、材料曲線與工程荷載。

## 尚未取得的工程能力

1. 實際 U 型肋 S8R 幾何、折彎圓角及離散鋁植釘／焊道連接剛度。
2. 鋁板面外風壓撓度、接觸開離、植釘軸／剪／彎受力、連接滑移、局部挫屈及製造容差。
3. 真實植釘間距造成的板件彎曲或荷載分布影響。本研究把 @300 只當站點標籤；**改變 x 座標但保持相同彈簧圖與剛度，求解結果不變**。
4. 材料強度、植釘與焊道容量、任何真實帷幕牆結構安全判斷。全數 `NOT_ADMITTED`。

下一步若要研究工程板肋及連接，先取得可追溯的真實構造材料、有效連接／接觸機制與獨立 benchmark，再擴展至板肋 S8R；不得把本合成彈簧網路視為已驗證的物理 U 型加勁肋。
