# 帷幕鋁板方案比較工作台｜研究版

本資料夾是獨立靜態網站（無伺服端計算）。瀏覽器內可比較鋁板及 U 型肋的**名目幾何體積**，並檢視一組不可外推的已完成合成數值研究。

- 幾何：板長／寬／厚、U 肋底寬／高度／厚度、肋數；肋長等於板長，忽略折彎圓角、損耗與連接細節。
- 固定基準：Stage 59／PR #96，100 × 100 × 2 mm 直肋共節點研究；不是開口 U 型肋。數值來源為 main@b52d29e5d725b54611a08479e1d58d8488cf37cb 的 TASKS.md。
- 無任意尺寸 FEA、實際風壓、植釘／焊接容量、接觸反力、強度或工程合格判定；未通過的 PR #131 不受本網站影響。
- 不會上傳輸入；沒有第三方套件、API、金鑰或使用者追蹤。

執行 `node site/test.mjs` 進行名目計算與固定證據的 deterministic 測試。由任意靜態檔案伺服器提供 `site/`，瀏覽器須支援 ES modules。
